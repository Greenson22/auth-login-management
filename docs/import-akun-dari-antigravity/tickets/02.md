# 02: ImportDialog skeleton + entri menu File

**What to build:** Pengguna bisa membuka dialog import dari menu File → "Import dari Antigravity…". Dialog menampilkan form lengkap dengan data yang dibaca dari Keyring: email (read-only), refresh token (tersembunyi dengan tombol reveal), project ID, dan kategori (bisa diedit). Di platform non-Linux, menu item dinonaktifkan dengan tooltip yang jelas. Validasi token dan fetch kuota belum dilakukan di tiket ini.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `QAction` "Import dari Antigravity…" ditambahkan ke menu File di `MainWindow`.
- [ ] Aksi dinonaktifkan (`setEnabled(False)`) dengan tooltip yang menjelaskan alasan ketika platform bukan Linux, D-Bus tidak tersedia, atau keyring terkunci — menggunakan `check_cli_availability()` yang sudah ada.
- [ ] Saat aksi dipicu, `ImportDialog` dibuka sebagai `QDialog` modal.
- [ ] `ImportDialog` menerima dependensinya lewat konstruktor: `keyring`, `oauth`, `db`, `password` — tidak ada singleton atau akses DB global.
- [ ] Dialog membaca Keyring Item via `KeyringReader.read_and_parse()` saat dibuka.
- [ ] Jika keyring error (tidak tersedia, terkunci, item tidak ada): dialog tidak terbuka, tampilkan `QMessageBox` dengan pesan yang jelas, hentikan alur.
- [ ] Form menampilkan: field email (read-only), refresh token (`SecureLineEdit` yang sudah ada), project ID (editable), kategori (editable text/dropdown).
- [ ] Tombol "Simpan" dan "Batal" ada. Batal menutup dialog tanpa perubahan.
- [ ] Tombol "Simpan" bisa diklik (validasi token tidak wajib selesai dulu di tiket ini).
- [ ] Test widget `tests/test_import_dialog.py` dibuat; kasus yang dicakup: dialog terbuka dengan data keyring; dialog tidak terbuka jika keyring tidak tersedia; tombol Batal menutup dialog tanpa perubahan DB.
