# 04: Fetch kuota async di ImportDialog

**What to build:** Setelah validasi token berhasil, kuota akun (Gemini Flash, Gemini Pro, Claude) beserta waktu reset diambil otomatis dari API di background dan ditampilkan di form sebagai read-only. Jika fetch kuota gagal karena apapun, form tetap tampil dengan kolom kuota kosong dan catatan kecil — fetch kuota tidak pernah memblokir alur simpan.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Fetch kuota dijalankan via `WorkerThread` segera setelah validasi token berhasil (token valid sebagai prasyarat).
- [ ] Jika token tidak valid atau validasi belum selesai: fetch kuota dilewati; kolom kuota tetap kosong.
- [ ] Form menampilkan field kuota read-only: Gemini (remaining fraction + reset time), Claude (remaining fraction + reset time).
- [ ] Selama fetch berlangsung: tampilkan indikator kecil "Mengambil kuota…" di area kuota.
- [ ] Jika fetch berhasil: tampilkan nilai kuota yang diambil.
- [ ] Jika fetch gagal (timeout, error jaringan, error API): kolom kuota tetap kosong; tampilkan note kecil "Kuota tidak berhasil diambil" (bukan error dialog); tombol "Simpan" tidak terpengaruh.
- [ ] Menggunakan `fetch_account_quota()` dari `quota_service.py` yang sudah ada.
- [ ] Test widget mencakup: token valid → kuota terisi setelah fetch; fetch kuota gagal → kuota kosong, note tampil, Simpan tetap bisa diklik.
